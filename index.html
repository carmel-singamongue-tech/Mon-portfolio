Projets

Une sélection de travaux en analyse de données et en Machine Learning.

ETL Football – Conception d'un entrepôt de données décisionnel

Conception et développement d'une solution décisionnelle permettant de centraliser, transformer et analyser les données d'une ligue de football. Le projet comprend la création d'un entrepôt de données selon une architecture en étoile, le développement d'une chaîne ETL avec Python et Pandas, ainsi que l'analyse des performances sportives, de la fréquentation des stades et des recettes de billetterie.

  • Python
  • Pandas
  • SQL
  • ETL
  • Data Warehouse
  • Business Intelligence
  • Visualisation de données
Voir le code source sur GitHub ↗

Régression linéaire – Modélisation et prédiction des ventes

Développement et comparaison de modèles de régression linéaire pour analyser et prédire les ventes à partir du budget publicitaire, du prix moyen et de la saisonnalité. Le travail couvre l'exploration des données, la descente de gradient implémentée manuellement, l'équation normale et l'utilisation de Scikit-learn. Les performances sont évaluées sur un jeu de test, avec un diagnostic des résidus et l'étude des régularisations Ridge et Lasso.

  • Python
  • NumPy
  • Pandas
  • Matplotlib
  • Scikit-learn
  • Régression linéaire
  • Ridge & Lasso
Voir le code source sur GitHub ↗

Régression logistique – Prédiction du risque de défaut

Développement d'un modèle de classification binaire destiné à estimer le risque de défaut de paiement à partir de variables financières telles que le revenu, l'endettement, l'ancienneté, l'épargne et les incidents. Le projet comprend l'implémentation de la régression logistique, la comparaison avec Scikit-learn, l'évaluation par matrice de confusion et métriques de classification, puis l'optimisation du seuil de décision en tenant compte des coûts des erreurs.

  • Python
  • NumPy
  • Pandas
  • Scikit-learn
  • Matplotlib
  • Classification binaire
  • Courbe ROC / AUC
